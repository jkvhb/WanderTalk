# 318 节点多源搜图对比试验设计

日期：2026-08-06  
状态：待用户复核后执行

## 1. 目的

先用少量真实难点验证不同图片来源，不直接改造现有自动配图功能。试验要回答三个问题：

1. 哪些来源更容易找到“确实属于这个节点”的图片；
2. 哪种组合能明显缩短整批等待时间；
3. 哪些结果只适合帮助发现线索，哪些结果具备进入最终视频所需的来源和许可信息。

## 2. 当前问题基线

现有流程由项目自行编排：AI 先生成检索词，然后逐节点、逐检索词调用 Pixabay；未命中时再调用 Wikimedia Commons；选中后逐张下载、压缩并存入本地。

这意味着 46 个节点、每点最多 4 个检索词、2 个图片来源时，理论上最多会产生约 368 次搜索请求，且主要串行等待。冷门地点越多，越容易走完整条降级链。Commons 的网络可用性不稳定，也会造成等待和失败。

## 3. 试验节点

固定选择 8 个容易暴露错图或覆盖不足的节点：

1. 金沙江大桥（容易错配成其他桥梁）；
2. G318/G248 交叉口（营官村附近，无正式景点名）；
3. 尼玛贡神山大型观景台旅游服务区；
4. 东达山垭口；
5. 姊妹湖；
6. 米堆冰川；
7. 色季拉山口；
8. 索松村。

每个节点使用同一份地点身份信息：正式名称、别名、行政区、经纬度、附近地标和视觉特征。这样可避免某个来源因为拿到了更多提示而获得不公平优势。

## 4. 对比来源

### A. 当前方案：Pixabay + Commons

作为基线，记录目前真实耗时、命中率、错误类型和失败次数。

### B. Pixabay + Openverse

Openverse 是开放许可媒体的聚合搜索。这里先把它作为 Commons 的更稳定替代候选，检查其中文冷门地点覆盖率和许可字段完整度。

### C. 地理位置优先：Mapillary

只用于道路、路口、垭口、服务区等可以通过坐标确认的节点。它的作用不是寻找“最美宣传照”，而是确认现实地点和道路环境。

### D. Brave Image Search

作为候选发现与证据来源，重点检查标题、摘要、发布网站和原始页面能否证明地点身份。未确认使用许可的图片只记录为“发现候选”，不自动进入视频。

第一轮若缺少 Brave 或 Mapillary 凭据，则先完成 A/B，并用公开网页检索验证 C/D 的覆盖可能性；不会把不可重复的网页结果伪装成 API 性能数据。

## 5. 统一检索策略

每个节点最多使用四级查询，找到足够合格结果后立即停止：

1. 正式名称 + 行政区；
2. 别名 + 邻近地标；
3. 英文名或拼音 + 行政区；
4. 坐标附近搜索（仅支持地理检索的来源）。

不再使用“川西高原”“雪山草原”这类过宽词语给严格地点节点兜底。宽泛图片可以用于章节氛围，但不能冒充具体节点。

## 6. 评分标准

每张候选图分别记录以下证据，而不是只给一个模糊总分：

- **地点身份（0～4）**：标题、标签、说明、来源页是否明确指向该节点；
- **区域一致（0～2）**：省、市、县、邻近地标是否一致；
- **视觉一致（0～2）**：是否符合底稿规定的桥梁、双湖、冰川、垭口等可见特征；
- **来源可追溯（0～1）**：是否能回到原始发布页；
- **许可完整（0～1）**：是否明确记录许可、作者和署名要求。

地点身份低于 3 分的图片不得作为“准确命中”。许可不完整不会改变地点准确性分数，但必须标为“仅作发现候选”。

## 7. 性能指标

每种方案记录：

- 首张准确图片出现时间；
- 每个节点找到 3 张合格图片的时间；
- 请求总数和失败数；
- 准确命中节点数；
- 明显错图数；
- 无可靠结果节点数；
- 可直接用于最终视频的图片数；
- 仅作发现候选的图片数。

## 8. 试验产物

输出一份表格化报告，逐节点列出各来源前三个候选、证据、许可状态、耗时和判定。图片只保存缩略图或来源链接，不写入用户当前行程，也不覆盖现有素材。

报告最后给出三类结论：

1. 正式自动配图应采用的主来源；
2. 仅在冷门节点启用的补充来源；
3. 暂不采用的来源及原因。

## 9. 后续改造方向（不属于本次试验）

若试验支持多源方案，正式实现再加入：

- 3～5 个节点并行处理（通俗说：不再一个个排队）；
- 按来源和检索词缓存；
- 429、5xx 等短暂错误的延迟重试；
- 某来源连续失败时暂时停用（通俗说：坏掉的来源不再拖累整批）；
- 先评分、后下载，只下载最终入选图片；
- 明确显示成功、部分成功、素材不足和来源故障。

## 10. 验收标准

本试验完成需满足：

- 8 个节点都有可复核记录；
- 当前方案与至少一个新来源完成相同条件对比；
- 不使用付费接口时不得产生费用；
- 不把版权未知候选标记为可直接使用；
- 所有结论能追溯到请求结果或原始来源页；
- 不修改现有行程、节点图片和视频素材。
