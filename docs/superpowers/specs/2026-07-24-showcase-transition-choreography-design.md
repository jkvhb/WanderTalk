# 展示转场与编排动效闭环设计

日期：2026-07-24  
状态：用户已确认，待实现计划

## 问题与根因

当前 `FlightPlayer.vue` 无条件以 `clip-path: circle(...)` 裁切整个展示页。Phase 4e 的 AI 配置只影响圆形揭幕**内部**的图片卡片；当节点只有一张图片、图片尚未加载完毕或没有图片时，页面回退为全屏铺底。因此用户看见的入口始终是圆形揭幕，AI 编排没有形成可辨识的节点级视觉差异。

此外，Vitest 当前未排除项目内 `.worktrees/`，主工作区会收集其他工作树的重复测试；在该目录外运行时实际基线为 35 个测试文件、340 条测试。实现前须修正此验证边界。

## 目标

让每个到站展示页的入口、内部编排和退出都由受限、确定性配置共同决定；圆形揭幕只作为旧配置、非法配置、无法执行的照片级转场或渲染失败时的可靠兜底。无论图片数量为 0、1 或多张，用户都能感受到节点之间的节奏差异。

## 非目标

- 不允许模型生成 CSS、JavaScript 或任意动画表达式。
- 不改变真实地图、路线、小车与音频时间线的事实层。
- 不接入实时视频生成、云层生成或逐句词级节拍。
- 不改动导出渲染器；所有新效果先保证网页预览可确定性重放。

## 受限转场词汇表

配置增加 `transition`，模型只能选择以下值：

| 值 | 视觉语义 | 适用素材 |
| --- | --- | --- |
| `route-bloom` | 从道路到站点向外扩散 | 默认和兜底；对应现有圆形揭幕 |
| `directional-wipe` | 沿下一段行进方向的柔和幕布推进 | 0～多图均可 |
| `photo-cascade` | 首张/卡片由行进方向错峰推入，地图随后淡出 | 多图最佳，单图可降级 |
| `soft-dissolve` | 地图与展示页交叉淡化，文字随后出现 | 0～多图均可 |

进入与退出分别配置，但退出仅允许与进入相同或 `soft-dissolve`，避免节点间风格跳变。`route-bloom` 保留为旧项目缺字段、任意非法配置、无法执行的照片级转场或渲染失败时的安全降级；减少动态效果偏好则统一使用 `soft-dissolve`。

## 配置契约与数据流

`/api/choreography` 的结果从：

```json
{ "tempo": "medium", "phases": [], "idle": { "drift": 0.4, "breathe": 0.3 } }
```

扩展为：

```json
{
  "tempo": "medium",
  "transition": { "enter": "photo-cascade", "exit": "soft-dissolve" },
  "phases": [],
  "idle": { "drift": 0.4, "breathe": 0.3 }
}
```

`normalizeChoreography` 负责白名单、默认值和素材数量降级；`compileChoreography` 继续只输出确定性参数。`FlightPlayer` 将外层展示页的 class/样式从固定 `clip-path` 改为按编译结果选择的渲染器。当前的地图预加载保持不变：地图未就绪时，退出阶段继续停留在遮罩状态。

## 可见性规则

- 0 图：`directional-wipe` 或 `soft-dissolve` 作用于深色文字页；`photo-cascade` 自动降级为 `route-bloom`。
- 1 图：不再只有不易察觉的呼吸；进入转场至少含一个可见的位移、淡入或方向性遮罩。
- 2～3 图：图片卡片的错峰入场必须与外层 `photo-cascade` 连贯，不被圆形裁切掩盖。
- 减少动态效果：强制 `soft-dissolve`，关闭漂移和脉冲，仍保留信息可读性。

## 验收与测试

1. 单元测试覆盖：白名单、非法值回退、0/1/多图降级、同配置同 seed 的确定性。
2. 组件/纯样式测试覆盖：配置可改变展示页根元素的转场标识，不再始终是圆形裁切。
3. 测试配置排除 `.worktrees/**`，主工作区与隔离工作区发现的测试集合一致。
4. 浏览器手测：至少选一个 0 图、一个 1 图、一个多图节点；在正常与减少动态效果下确认入口、正文、退出；拖动时间轴进入转场边缘不闪黑、不露出未加载地图。

## 发布约束

先在“康定—折多山—新都桥”样章验证词汇表与节奏，再推广到固定 318 全程。AI 生成失败或旧项目缺少新字段时必须保持可播放，并回退 `route-bloom`。
